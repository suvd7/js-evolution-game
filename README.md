# JavaScript Evolution Game
A browser-based game where players collect evolution chains by merging technologies. The game challenges players to earn points before the timer runs out.

## Features
- Random technology pictures per round
- Multiple difficulty levels (Easy, Medium, Hard)
- Time-based gameplay
- Score system based on correct merges

## Technologies Used
- HTML, CSS, JavaScript

## How to Play
1. Select a difficulty level.
2. Start the game to see the technology images.
3. Merge related technologies to complete evolution chains.
4. Try to collect as many as possible before time runs out!
